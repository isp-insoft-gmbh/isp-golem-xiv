# Golems on GitHub

A golem is one Markdown file in a repository's `.golems/` directory.
It can answer a question in a thread or propose a change in a pull request.
A human decides what to do with the result: golems never merge, approve, or request changes.

1. [Enable golems](enable.md) in an organization repository.
2. [Register a seat](seats.md) to run a golem on your subscription.
3. [Ask the golem to run](run.md) from an issue or pull request.

To define your own task, [write a golem](write.md) and review it like any other change to the repository.

The [latest release](release.md) shows what shipped; the [CI report](reports.md) shows what the tests measured on `trunk`.
Neither tells you which runner is pinned in private operations.
