About repository states

Configured means the repository has .golems/. It can still have disabled definitions or no definitions. Unknown means metadata was unavailable, not that the repository is unconfigured.

How to read these numbers
  • Runs use Actions creation time for the 30-day window; requests that never started use final check time.
  • Only loaded, verified audits contribute to usage and outcome totals. Runs from before 2026-11-13 predate audits and are counted separately; no history is invented.
  • Duration is Actions start to final target check completion, not agent-only or billing time.
  • Unknown means no verified observation. Seats show their latest successful and blocked runs among loaded audits; sign-in expiry and refresh state are not recorded, and a secret's update time is not its expiry.
  • Workflow failure rate uses failed, timed-out, startup-failure, action-required and stale conclusions over loaded completed workflows.
  • Pagination is bounded to 1,000 workflows and 100 pages per listing. Changing upstream data can shift pages; a scan limit leaves totals incomplete.
  • Seats may include normalized identifiers for people who left. Repository metadata can be unavailable without the repository being disabled.
